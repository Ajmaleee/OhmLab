OhmLab

Plain HTML, CSS, and JavaScript resistor & electronics calculator site.

## Structure

- `index.html` - Home page (Vite entry point)
- `public/` - All static pages, styles, and scripts
  - `styles.css` - Shared styles
  - `navigation.js` - Shared header/footer/menu rendering
  - `pages/` - Page-specific render scripts
  - `*.html` - Individual pages (about, contact, calculators, legal)
